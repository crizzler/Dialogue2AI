# Dialogue2AI

Immersive NPCs: Living Dialogue System for Unity.

This repository contains the Unity asset source under `Assets/ImmersiveNPCs`. It is scoped to the asset package rather than the full Unity project, so generated Unity folders, downloaded local models, and unrelated project assets are intentionally excluded.

## Documentation

- Asset README: [Assets/ImmersiveNPCs/README.md](Assets/ImmersiveNPCs/README.md)
- Quick start: [Assets/ImmersiveNPCs/Documentation/QUICKSTART.md](Assets/ImmersiveNPCs/Documentation/QUICKSTART.md)
- License: [MIT](Assets/ImmersiveNPCs/LICENSE.md)

## Included

- Runtime dialogue pipeline, provider abstraction, memory, cache, and world-state systems.
- Editor settings, diagnostics, Hugging Face browser, model scanner, and template wizard.
- Yarn Spinner dialogue adapter and example scene.
- Local backends for in-process GGUF, Sentis, Ollama, OpenAI-compatible servers, and cloud providers.
- Tests and third-party notices.

## Install

Copy or import `Assets/ImmersiveNPCs` into a Unity project, then follow the [quick start](Assets/ImmersiveNPCs/Documentation/QUICKSTART.md).
